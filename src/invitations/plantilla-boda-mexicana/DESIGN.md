# Mexican Wedding Template — Design Brief

## Visual identity

Traditional Mexican artisanal wedding invitation digitized for web.
Papel picado banners, flores mexicanas, corazones, and hand-crafted textures.

## Palette

| Token | Hex | Usage |
|-------|-----|-------|
| Terracotta | `#C2533A` | Primary accent, buttons, borders |
| Coral | `#E8734A` | Secondary warm accent |
| Rosa mexicano | `#E0457B` | CTA buttons, romantic accents |
| Mostaza | `#D4A533` | Gold touches, countdown labels |
| Azul cielo | `#5CAACC` | Floral details |
| Azul intenso | `#2356A0` | Floral details, gift button |
| Verde | `#3B7A3B` | Leaves, timeline dots |
| Morado | `#7B4F9D` | Accent variety |
| Crema | `#F5EDDC` | Base background |

## Typography

- **Display/Titles**: Playfair Display 700
- **Names/Script**: Dancing Script 700
- **Body**: Outfit 400–600

## Architecture

`standalone-custom` — single JSX + CSS file pair.
All decorative elements are inline SVGs. No external images needed for the UI.

## Constraints

- No white/gold European wedding aesthetic.
- No minimalist design.
- No person photographs.
- Must feel handmade, warm, and distinctly Mexican.
- Mobile-first, scroll-to-discover experience.
