# DESIGN – Eiza Camila · Mis XV Años

## Theme
Sky-blue and plumbago-blue palette inspired by Eiza's dress and balloon accents.
Ethereal, dreamy, feminine aesthetic with a fairy-tale feel.

## Color palette
| Token         | Hex     | Role                      |
|---------------|---------|---------------------------|
| `--maia-ink`    | #2a3545 | Body text, dark surfaces   |
| `--maia-forest` | #4a6fa5 | Accent headings, icons     |
| `--maia-moss`   | #6a8fbe | Secondary accents          |
| `--maia-gold`   | #8ba8c8 | Eyebrows, lines, swatches  |
| `--maia-paper`  | #dce8f4 | Light panel backgrounds    |
| `--maia-cream`  | #f4f8fc | Page background            |

## Typography
- Display: **Italiana** (serif)
- Script: **Mrs Saint Delafield** (cursive)
- Body: **Manrope** (sans-serif, weight 300–600)

## Dress code
Formal. Reserved colors: azul plumbago and azul cielo.
